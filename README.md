## About
- 물류 관리 및 배송 시스템을 위한 MSA(Microservices Architecture) 기반 플랫폼입니다.
- MSA의 복잡성을 이해하고, 팀원들과 함께 MSA를 구축하면서 실무에서 발생할 수 있는 다양한 문제들을 간접적으로 경험하고 해결하는 것을 목표로 합니다.
